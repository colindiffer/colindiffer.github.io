Before You Contact Support

  • Check that you are using the latest app version available in the App Store or Google Play.
  • If a purchase did not unlock correctly, reopen the app and try the Restore Purchases button in Settings.
  • If syncing is not behaving as expected, confirm you are signed into the same account on each device.
  • For timer or audio issues, restart the app and test one of the built-in presets first.

Common Questions

How do I restore the ad-free purchase?

Open Settings in the app and tap Restore Purchases while signed into the same store account that made the original purchase.

How does sync work?

Sync is optional. If you sign in, you can upload your workouts and restore them later on another device using the same account.

What should I include in a support email?

Please include your device model, OS version, app version, and a short description of what happened so the issue can be reproduced.

Do you support iPad?

Yes. Flash Interval Timer Workout is intended to run on iPad as well as iPhone, with the same core timer, workout builder, and settings flows.
